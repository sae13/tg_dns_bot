# tg-dns-bot

بات تلگرام درخواستمحور برای استقرار روی کلودفلر ورکرز.

## پیشنیازها

- نسخهٔ پشتیبانیشدهٔ نود مطابق پروندهٔ بسته
- حساب کلودفلر و ابزار ورنگلر
- توکن بات تلگرام

## راهاندازی محلی

وابستگیها را نصب کنید:

`npm ci`

برای اجرای محلی، رازهای زیر را فقط در پروندهٔ محلی نادیدهگرفتهشده قرار دهید:

- `BOT_TOKEN`
- `TELEGRAM_WEBHOOK_SECRET`

تنظیمات غیرمحرمانه در پروندهٔ ورنگلر قرار دارند. رازها را هرگز در آن پرونده یا مخزن ثبت نکنید.

فرمانهای راستیآزمایی:

- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npx wrangler deploy --dry-run`

## استقرار

رازهای ورکر را ثبت کنید:

- `npx wrangler secret put BOT_TOKEN`
- `npx wrangler secret put TELEGRAM_WEBHOOK_SECRET`

ورکر را مستقر کنید:

`npm run deploy`

سپس متغیرهای محلی فرمان ثبت وبهوک را تنظیم کنید:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_WEBHOOK_SECRET`
- `TELEGRAM_WEBHOOK_URL`

نشانی وبهوک باید نشانی کامل مسیر زیر روی ورکر مستقرشده باشد:

`/webhook`

وبهوک را ثبت و بلافاصله بازخوانی و راستیآزمایی کنید:

`npm run set-webhook`

مسیر سلامت:

`/health`

## چرخش راز وبهوک

ابتدا راز تازه را در ورکر ثبت و استقرار را کامل کنید؛ سپس فرمان ثبت وبهوک را با همان راز تازه اجرا کنید. پس از راستیآزمایی نشانی، راز قدیمی را از محیطهای محلی حذف کنید.

## بازگشت

در صورت شکست ثبت وبهوک، نسخهٔ پیشین ورکر را با تاریخچهٔ استقرار کلودفلر برگردانید و وبهوک را دوباره با نشانی و راز نسخهٔ سالم ثبت و راستیآزمایی کنید. هیچ فرمان استقرار یا ثبت وبهوک نباید توکن را در خروجی چاپ کند.
